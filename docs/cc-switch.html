CC Switch 是什么

CC Switch（官网 ccswitch.io）是一个开源的跨平台桌面工具，可以理解为命令行 AI 编程工具的"供应商管理器"。它统一管理 Claude Code、Codex、OpenCode、Grok Build 等工具的接入配置：

  • 多供应商配置卡片：把官方 Anthropic、各种中转站、DeepSeek 等第三方都配置成一张张"卡片"，界面里一键切换当前生效的供应商；
  • 切换原理：切换时自动改写对应工具的配置文件（如 ~/.claude/settings.json 里的 ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN / ANTHROPIC_MODEL 等环境变量段）；
  • 格式转换/路由：支持 Anthropic Messages 和 OpenAI 两种上游格式互转（路由模式），让"只说 OpenAI 方言"的模型也能被 Claude Code 调用；
  • 周边管理：连通性检查、用量统计与请求日志、MCP / 提示词 / Skills 统一管理、自动备份（数据在 ~/.cc-switch，默认每 24 小时备份，保留最近 10 份）。

为什么需要它

Claude Code 客户端默认只对接 Anthropic 官方账号，而国内注册、付款都不方便。好消息是 Claude Code 只认协议，不认公司：只要一个服务实现了 Anthropic Messages 协议（改 base_url + key + 模型名），它就能当 Claude Code 的"发动机"。CC Switch 把"换发动机"这件事从"手改配置文件"变成"点一下"。

下载与安装

  • 官网/GitHub Releases 下载：Windows 有 CC-Switch-v{版本}-Windows.msi（安装版）和 Portable.zip（免安装版），ARM 设备有专门的 arm64 包；
  • macOS / Linux 同样有对应安装包和 Flatpak；
  • 本机已就位：E:\cc-switch\cc-switch.exe（便携版），双击即用。

买 Key：国内按量付费首选 DeepSeek

选择标准：国内能注册能付款、按量计费（充值制，非包月）、协议兼容。按这三条筛，DeepSeek 是当前最省心的首选。

购买步骤（约 5 分钟）

  1. 打开 platform.deepseek.com，手机号注册登录；
  2. 左侧「充值」页面充值（支持微信/支付宝），首次建议充 ¥50 试水；
  3. 「API Keys」页面创建密钥，得到 sk-... 开头的 Key（只显示一次，立即复制保存）；
  4. 计费方式：按 tokens 用量扣余额，用多少扣多少，没有包月、没有最低消费，不用时零花费。

配置：把 DeepSeek 接进 CC Switch

在 CC Switch 里「添加供应商」→ 类型选 Claude / Anthropic，填：

字段填什么说明
Base URLhttps://api.deepseek.com/anthropicDeepSeek 的 Anthropic 兼容端点
API Keysk-...platform.deepseek.com 生成
主模型deepseek-flash日常开发够用，价格友好
子代理模型deepseek-flash子智能体用量大，用 flash 控成本
Opus 档模型deepseek-v4-pro复杂任务时手动切换用

不填模型名也行：DeepSeek 服务端会自动映射——claude-opus* 请求映射到 deepseek-v4-pro（按 v4-pro 计费），claude-sonnet/haiku* 映射到 deepseek-flash。想控成本就显式把主/子模型都填成 deepseek-flash。

不想装 CC Switch 也可以直接用环境变量（PowerShell）：

$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="sk-你的Key"
$env:ANTHROPIC_MODEL="deepseek-flash"
$env:CLAUDE_CODE_SUBAGENT_MODEL="deepseek-flash"

设置后当前终端里运行 claude 即走 DeepSeek。想永久生效就写进系统环境变量。

接法都一样：Base URL + Key + 模型名三件套。只有 Anthropic 格式的能直连（Claude 类型供应商卡），OpenAI 格式的需要在 CC Switch 里用路由模式转换。

常见问题与注意事项

  • 连通性检查通过 ≠ 能用：检查只测地址可达，不验证 Key 和模型名。配完跑一次真实对话才算数；
  • 报 404/405：多半是上游格式选错——Claude 系工具选 Anthropic Messages 格式；
  • Key 安全：Key 等同钱包，别发群里、别提交进仓库；CC Switch 的数据（含 Key）明文存本机 ~/.cc-switch，电脑共用环境注意；
  • 成本控制：平台页面看实时用量；子代理模型用便宜档位；错峰跑长任务；子代理模型别设成贵的；
  • 遇到限流：个人 Key 并发有限制，跑 OMC 多智能体（team 模式多 Agent 并行）时注意并发上限，必要时错峰或分批。
