附录 常用命令速查表

A.1 Claude Code 内置

/clear                    清空上下文,开新任务
/compact                  压缩历史,省 token
/model                    切换模型档位
/resume                   恢复会话
Shift+Tab                 计划模式/权限模式切换
Esc / 双击 Esc             打断 / 回退到历史消息重新指挥
@文件名                    精确引用文件
claude -p "..."           非交互模式(脚本调用)

A.2 OMC 技能速查(oh-my-claudecode:)

技能一句话用途
plan规划:调研并产出可执行计划
execute执行:按计划实现并验证
review审查:独立上下文 code-reviewer
verify验证:证据确认"真的做完了"
autopilot全自动驾驶:目标进,结果出
ralph循环直到完成(可配置审查者)
ultragoal持久多目标台账(.omc/ultragoal)
teamN 个 Agent 协同共享任务列表
research有出处的调研报告
trace / debug证据驱动的调试与调用链追踪
deep-interview/ralplan需求澄清后规划
deepinit分层 AGENTS.md 文档树生成
remember知识分类决策(记忆/wiki/技能)
skillify把会话流程固化成技能
wiki持久 markdown 知识库
tdd测试先行,在预定接缝处
ai-slop-cleaner清理 AI 生成的冗余代码
cancel取消任何 OMC 模式
omc-setup / omc-doctor安装刷新 / 安装诊断

A.3 OMC 状态根(.omc/)地图

.omc/
├── state/         编排模式进行时状态(可恢复)
├── plans/         计划文档
├── research/      调研产物
├── logs/          日志
├── artifacts/     产物(本 EPUB 源文件也在这里)
├── handoffs/      会话交接
├── notepad.md     分区工作笔记
├── project-memory.json  结构化项目记忆
└── wiki/          持久知识库
